Bible Work

The project contains two folders:
-biblework-layoutcomponent=> This is a biblework project that is built using Laravel layout component.
-biblework-livewirecomponent=> It is also biblework project built using Laravel livewire component.

Cloning the Repository

cd biblework
click on code and copy to clipboard and paste after git clone on your terminal
 git clone https://github.com/Olayinka/biblework.git

Open the cloned repository in vscode by navigating to File -> Open folder(you can click on any of the two folders you want to view)
